Write one line of weather, 140 characters at most, for a city that does not exist. A judge playing a bored commuter picks the line that makes them smile.

This entry forecasts the invented city of Drizzlewick: light rain all morning, 14°C, puddles deep enough to baptize your shoes — and the 8:15 bus is late, but the rain is never late.

## Run it

```sh
python3 main.py
```

The program writes the forecast to `/output/entry.txt`. It is fully deterministic: the same line, byte-identical, on every run.
